Bot commands

parameters with an asterisk are required, you can also pipe in parameters by replying to a message

Command Usage Description
%help (%commands) %help gives a link to this page
%ping %ping just says the uptime of the bot
prefix? prefix? says what the current prefix is
%setprefix %setprefix *[prefix] change the prefix
%join (%part) %join [channel] join or part the bot in a channel
%link (%unlink) %link *[lastfm|letterboxd|osu] *[username] link or unlink an external account
%letterboxd (%boxd, %lb) %letterboxd [username] returns some information about a letterboxd user's most recently logged film
%movie (%film, %mv) %movie *[query] returns some information about a movie on letterboxd
%moviegame (%mg, %higherlower, %hl) %moviegame [left|right|1|2|leaderboard|stats|best] plays the letterboxd higher/lower game or shows its leaderboard and stats
%rating (%review, %rt) %rating [username] *[query] returns a user's rating and review of a logged movie on letterboxd
%song (%s, %sc) %song [username] shows a lastfm user's most recently played song; %sc includes play count
%whoknows (%wk, %w) %whoknows [artist] [flags] shows play counts for users with lastfm linked for an artist
%wkt %wkt *[artist - track or track] [flags] shows users that know a track
%artist (%a) %artist [username] [artist] shows an artist's top tracks, optionally for another user
%plays (%p) %plays [username] [artist] shows a user's play count for an artist
%config %config *[system] *[property] *[value] configures lastfm or whoknows preferences
%trivia (%triv) %trivia [category|categories|skip|stats|leaderboard] [flags] starts trivia or shows trivia categories, stats, and leaderboard
%paste %paste *[text] uploads text and returns a paste link
%fortune (%f, %cookie) %fortune [options] daily fortune message with a streak if you do it everyday
%searchlogs (%sl) %searchlogs *[channel] *[user] *[query] search somebody's logs for something using bestlogs
%connections (%conn, %c) %connections [user] [platform] lists the potatbotat connections of a user
%listcmds (%listcmd, %lc) %listcmds [username] returns a link to a user's custom potatbotat commands
%namechange (%nc) %namechange [user] view a user's previous usernames
%newname (%nn) %newname *[username] try to find a current username from an old one using supibot database
%randomline (%rl) %randomline [username] or %randomline *[channel] *[username] returns a random line from logs
%download (%dl) %download [slide-index] *[URL] downloads and hosts supported media when enabled
%osu %osu [username|recent|top|best] shows an osu! profile, recent plays, or top plays
%unicode (%u) %unicode *[message] gives you a link to a website that lets you identify what unicode characters a message contains
